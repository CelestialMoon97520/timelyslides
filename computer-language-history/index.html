01 · 史前时代

没有计算机的时代，先有了"程序"的思想

1834-1940：齿轮与继电器奏响的前奏曲。

👩‍💻 Ada Lovelace · 1843

为巴贝奇的分析机撰写第一份算法——伯努利数计算。她预见到计算机不仅能算数，还能处理符号、创作音乐。世界上第一位程序员。

1843
第一个算法诞生

🧠 Alan Turing · 1936

发表《论可计算数》，提出通用图灵机构想——任何可计算问题都能用一台机器解决。现代计算机的理论基石。

1936
图灵机论文发表
1854
乔治·布尔发表《思维定律》——布尔代数成为所有计算机的逻辑基础
1936
康拉德·楚泽在柏林造出Z1机械计算机，约1945年设计出第一种高级语言 Plankalkül
02 · 第一代

电子管 1940-1956：从零和一开始

ENIAC 重30吨，18000只真空管，功耗140kW——编程就是插拔电缆、拨动开关。

⚡ ENIAC 编程

没有键盘，没有屏幕。六位女数学家通过重新布线插头来"写程序"。改变一次程序需要数天时间。

📜 机器语言 & 汇编

纯二进制指令。1949年 EDSAC 引入第一个子程序库（David Wheeler）。汇编语言让程序员终于不用只写0和1。

18,000
ENIAC 真空管数量
1947
贝尔实验室发明晶体管
1952
Grace Hopper 写出 A-0 编译器

关键人物：Grace Hopper —— 她坚信编程应该用英文而非数字，力排众议写出了世界上第一个编译器。今天所有高级语言的源头，都有她的影子。

03 · 第二代

晶体管 1956-1964：高级语言的黄金时代

晶体管取代真空管——更小、更快、更可靠。真正的高级编程语言集中爆发。

🔬 FORTRAN · 1957

John Backus @ IBM。第一种广泛成功的高级语言。科学计算的王者，至今仍用于超算。引入了编译器、循环、子程序的概念。

1957
"Formula Translation"

🧪 LISP · 1958

John McCarthy @ MIT。第二种至今仍活着的语言。AI 研究的母语。引入递归、条件表达式、垃圾回收、符号计算。

1958
"LISt Processing"

📊 COBOL · 1959

Grace Hopper 主导。英语式语法，商业应用。90%的商业系统用了20+年。长变量名、层次化数据结构、嵌套选择。

1959
"Common Business-Oriented Language"

📐 ALGOL 60

委员会设计的学术语言。提出 BNF 范式、块结构、嵌套if-then-else、递归子程序。Pascal、C、Java 的共同祖先。

🎓 BASIC · 1964

Dartmouth 学院。为初学者设计。简单语法让编程不再高不可攀。Bill Gates 的编程启蒙语言。

04 · 第三代

集成电路 1964-1971：OOP 的种子

Jack Kilby 和 Robert Noyce 发明集成电路，计算机进入"芯片"时代。

🧬 Simula · 1965

Dahl & Nygaard @ 挪威。基于 ALGOL 60。引入类、对象、继承、动态绑定——面向对象编程的诞生。这是编程思维的一次范式革命。

OOP
面向对象编程元年

🔧 UNIX 诞生 · 1969

Ken Thompson 和 Dennis Ritchie 在 Bell Labs 开始开发 UNIX。这为后来的 C 语言埋下了伏笔——操作系统需要一种高效的系统编程语言。

1969
UNIX + ARPANET 同年
集成电路晶体管数
~1000
真空管时代
~1

质的飞跃：一个指甲盖大小的芯片集成了上千个晶体管，电子移动距离缩短，速度飞跃。操作系统与多道程序概念开始出现。

05 · 第四代

微处理器 1971-1990：PC 革命

Intel 4004 —— 2300个晶体管，12mm²，把一间屋子的计算机塞进一颗芯片。

⚡ C · 1972

Dennis Ritchie @ Bell Labs。为 UNIX 而生。兼具高级语言的便利和底层内存控制能力。C++、Java、C#、Python 的共同根基。

🖱️ Smalltalk · 1972

Alan Kay @ Xerox PARC。完善并普及了 OOP。首创 IDE、GUI、鼠标驱动的图形界面——启发乔布斯造出 Macintosh。

🔍 Prolog · 1972

逻辑编程语言。AI、定理证明、自然语言处理的利器。1972年同一年诞生了 C、Smalltalk、Prolog——编程范式的三岔口。

🏗️ C++ · 1979

Bjarne Stroustrup。给 C 加上类、继承、多态、封装。1983年更名 C++。系统软件和游戏的王者。

📚 Pascal · 1970

Niklaus Wirth。结构化编程教学语言。整个80年代的程序员都是学 Pascal 长大的。

06 · 互联网时代

微处理器 1990-2010：Web 改写一切

1989年 Tim Berners-Lee 发明万维网。浏览器变成了新的"操作系统"。

🐍 Python · 1991

Guido van Rossum。可读性至上，多范式。如今是 AI 和数据科学的第一语言。

#1
AI 时代第一语言

☕ Java · 1995

James Gosling @ Sun。"Write Once, Run Anywhere"。JVM 革命，企业级霸主。

服务器端脚本。Facebook、Wikipedia 的早期技术选型。Web 2.0 的基础设施。

07 · 现代语言

2010-2025：安全、并发、效率的新追求

多核、云原生、移动端——新需求催生新一代语言。

🦀 Rust · 2015

Mozilla 出品。零成本抽象 + 所有权系统 = 内存安全无需 GC。连续七年 Stack Overflow 最受喜爱语言。Linux 内核、Windows 内核已引入 Rust。

#1
7年最受喜爱语言

🍎 Swift · 2014

Apple 替代 Objective-C 的现代语言。Protocol-oriented 设计，Playground 即时反馈。iOS/macOS 开发生态的核心。

2014
WWDC 发布即震撼

🔷 TypeScript

微软出品，JS的超集。给动态语言加上类型安全。已成为大型前端项目的标配。

🏗️ Kotlin

JetBrains 的 JVM 语言。Google 钦定 Android 首选语言。简洁、安全、与Java无缝互操作。

🔥 Mojo

2024年 Modular 发布。Python 语法 + C 性能。专为 AI 硬件设计，可能是 AI 时代的"新 C 语言"。

09 · AI 芯片战争

GPU vs TPU vs ASIC：算力军备竞赛

2012年 AlexNet 用两块 GTX 580 夺冠，GPU 意外成为 AI 训练的标配。此后十年，算力竞赛全面爆发。

🟢 NVIDIA GPU 路线

CUDA (2006) → Tensor Core (V100/2017) → A100 (2020) → H100 (2022) → Blackwell B200 (2024)
从 FP32 到 FP4，精度每降一级能效翻倍。十年性能提升 1000 倍。

🟣 Google TPU 路线

TPU v1 (2015) 推理专用 → v2 支持训练，发明 bfloat16 → v4 OCS光交换 → v7 Ironwood (2025)：4614 TFLOPS，42.5 EFLOPS 集群。首次超越同代 NVIDIA。

10 · AI 时代的编程

代码不再是唯一的语言

从手写规则到神经网络，从编程语言到自然语言——编程范式的又一次巨变。

🧠 深度学习框架

TensorFlow (2015) → PyTorch (2016) → JAX (2018)
框架取代了手写梯度计算。Python 凭借生态系统成为 AI 时代的"新英语"。

💬 大语言模型

GPT 系列 (2018-) → LLaMA → Claude → DeepSeek
"编程"不再是写代码——Prompt Engineering 成了新型编程语言。

Prompt

模型学会调用工具、操作终端、自主完成任务。编程从"告诉计算机怎么做"变成"告诉计算机要什么"。

11 · 未来展望

下一站在哪里？

从齿轮到量子比特——计算机语言的进化从未停止。

⚛️ 量子计算

量子比特取代经典比特。Qiskit、Cirq 等量子编程语言已经出现。量子算法需要全新的编程思维——叠加态、纠缠、量子门。

🧬 神经形态计算

模仿人脑结构——脉冲神经网络（SNN）直接在硬件上运行。Intel Loihi 2 已有100万神经元。编程 = 设计大脑结构。

🤖 AGI 编程

通用人工智能——机器能理解并完成任何智力任务。届时"编程"或许就是对话本身。人类从"写代码的人"变成"定义目标的人"。

🌌 存内计算

打破冯·诺依曼瓶颈——计算和存储合二为一。忆阻器、3D堆叠。能耗降低1000倍。硬件架构将再次改写编程范式。

180年，从齿轮到智能

📌 核心启示

硬件定义了语言的边界，语言拓展了人类的思维。

从 Ada 的第一份算法到 GPT 的万亿参数——不变的是人类用符号驾驭计算的渴望。

每一次"编程变得更简单"，都意味着更多人能参与创造。

🔮 不变的趋势

抽象层不断升高：机器码→汇编→高级语言→框架→自然语言。

但底层——从电子管到 TPU——始终在追求：更快、更小、更高效。
