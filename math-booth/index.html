22. 综合与实践 · 爱心义卖遮阳区问题

拖动滑块观察遮阳伞平移过程中遮阳区的形状与面积变化

题目背景

矩形义卖区 ABCD，遮阳伞投影为平行四边形 ▱MNPQ。

固定参数：

  • 矩形：AB=3m，BC=2.5m
  • 平行四边形：MN=3m，高=2m，面积=6m²
  • 初始：AN=1m，AP=2m，P在AD上

设向右移动距离为 x m，遮阳区面积为 S m²。

问题解析

（1）直观感知

S 随 x 增大而逐渐增大

（2）图3情形的 x 与 S

x = 3 m，S = 5 m²

（3）图3到M与A重合的解析式

S = -2x² + 14x - 19 （3 ≤ x ≤ 4）

（4）面积最大时的移动距离

向右移动了 3.5 m（7/2 m）

全程分段函数

区间 解析式 形状
0 ≤ x ≤ 1 S = x² 直角三角形
1 < x ≤ 3 S = 2x - 1 直角梯形
3 < x ≤ 4 S = -2x²+14x-19 六边形（最大值）
4 < x ≤ 6 S = 13 - 2x 直角梯形
6 < x ≤ 7 S = (x-7)² 直角三角形
