02 · 解答

问题(1)(2)：直观感知 + 初步探究

(1) S 随 x 如何变化？

通过动态演示观察：

x 从 0→3 过程中，S 先增大后减小
x=0 时 S=4
x≈1 时 S 达到最大 5
x=3（图3）时 S=2

(2) 图3情形的 x 与 S

图3：点 P 落在 BC 上
BC 是矩形右边界，x=3

x = 3 m
此时遮阳区为三角形：
S = 2 m²
03 · 解答

问题(3)：S 关于 x 的解析式

从图3（x=3）继续右移至 M 与 A 重合（x=2）

当 2 ≤ x ≤ 3 时：

S(x) = 8 − 2x

遮阳区为梯形，面积随 x 线性减小

x (m)遮阳区形状S (m²)公式
0 ≤ x ≤ 2五边形 → 梯形4+2x−x²二次函数
2 ≤ x ≤ 3梯形 → 三角形8−2x线性递减

04 · 解答

问题(4)：面积最大时移动了多少？

📈 求最大值

S(x) = 4 + 2x − x²（0≤x≤2）
对称轴：x = −b/(2a) = 1

S(0) = 4
S(1) = 5 ← 最大值
S(2) = 4

✅ 结论

当遮阳区面积最大时：

x = 1 米

最大面积：S = 5 m²

此时遮阳伞刚好有一半在矩形正上方
